# Adrian Rasmussen Art Website

## Project Overview
Personal art website for Adrian Rasmussen, a multidisciplinary artist based in Bali. The site showcases creations, writings, a shop, and commission inquiries.

## Tech Stack
- Vite + React 18 + React Router v7 + Tailwind CSS 4.2 + TypeScript
- No backend — all data lives in `src/data/mockData.ts`
- Deployed on Cloudflare Pages (merging to `main` triggers deploy)
- Stripe for payments (Checkout Sessions)

## Design System
- **Color palette:** paper / wood / stone / bronze (defined in `src/index.css`)
- **Fonts:** Cormorant Garamond (serif body), Lato (sans), Cinzel (titles)
- **No icons, no badges, no stickers** — text and color only for states
- **No em dashes** in any copy — use commas, periods, or "to" for ranges

## Site Architecture

### Pages & Routes
- `/` — Homepage with hero, Selected Works, about preview
- `/creations` — 8 category tiles (Multi Art, Illuminated Works, Jewelry, Oracle Cards, Tables, Installations, Objects, Spaces)
- `/creations/multidimensional-art` — Hub page with subcategory tiles
- `/creations/multidimensional-art/:subcategory` — Subcategory pages (universal-language, mandala, light-codes, signature-pieces)
- `/creations/illuminated-works` — Experiential page about illuminated art
- `/creations/:id` — Individual piece pages
- `/oracle/universal-language` — Interactive oracle deck index (all 64 cards). This is the card product, not the art series.
- `/oracle/universal-language/:number` — Individual oracle card detail
- `/writings` — Stories, essays, explorations
- `/writings/:slug` — Individual writing pages
- `/shop` — Ready-to-ship and made-to-order items
- `/inquire` — Commission inquiry form
- `/about` — Artist bio and philosophy
- `/teajia` — Tea culture project

### Universal Language — two distinct things
The name "Universal Language" refers to two separate products that share the same 64 artwork images:
1. **Art series** at `/creations/multidimensional-art/universal-language` — 64 original airbrushed paintings on laser-cut wood. Fine art. No "oracle" framing here.
2. **Oracle deck** at `/oracle/universal-language` — interactive card reader / physical product. Oracle framing is correct here.

Do not conflate them. The Oracle Cards tile on `/creations` links to `/oracle/universal-language`.

### Key Components
- `src/components/` — All React components
- `src/data/mockData.ts` — All artwork, writing, and product data
- `src/types.ts` — TypeScript type definitions

## Voice & Tone
- Personal, mystical, but non-prescriptive
- Never pushy or commercial-feeling
- Use middle dot separator (·) for inline piece details (dimensions · material · year)

## SEO Rules (enforced — do not override)
- **Never use "wall art"** anywhere on the site — brand-excluded
- **Never use "oracle" in art-series SEO** (alt text, titles, meta descriptions for the fine art pieces or `/creations/multidimensional-art/*` routes). Oracle framing belongs only on `/oracle/*` routes.
- **Universal Language alt text pattern:** `[Piece Name], Universal Language [Number]. Original airbrushed painting on laser-cut wood by Adrian Rasmussen.` — generated by `utils/universalLanguage.ts`
- **Universal Language meta title pattern:** `[Piece Name] · Universal Language · Mandala Art | Adrian Rasmussen`
- **Universal Language meta description pattern:** `Original airbrushed painting on laser-cut wood, connected to [Hexagram Name] (Hexagram [N]) of the I Ching and Gene Key [N]: [Gift]. One of 64 multidimensional artworks by Adrian Rasmussen.`
- **Cloudinary filename convention for new UL uploads:** `universal-language-[number]-[piece-name-slug]` (e.g. `universal-language-32-art-of-living`). Do not rename existing files.
- For UL pieces, "sculpture" is inaccurate — they are airbrushed paintings on laser-cut wood. Reserve "sculpture" for Light Codes / Signature Pieces.

## Working With This Codebase
- When editing components, check `mockData.ts` for data structure
- Route order in `App.tsx` matters — static routes before `:id` catch-all
- Categories with a `link` property in `CREATION_CATEGORIES` use Router navigation; others use filter state
- Bidirectional story linking: pieces have `relatedStorySlug`, writings check `location.state.openStory`
